# 분석에서 확인한 점

이 문서는 로컬 데이터에서 계산한 핵심 집계 결과와 그에 대한 해석을 요약합니다. 개별 행, 분자 구조 문자열, 지문 벡터, 상세 표와 시각화는 포함하지 않습니다. 원본 데이터가 배포되지 않으므로 이 저장소만으로 아래 수치를 재현할 수는 없습니다. 다른 입력으로 실행하면 결과도 달라집니다.

## 1. 결측치 점검만으로 입력 품질을 판단하기 어렵다

결측치와 완전 중복 행이 없어도 모델에 들어가는 숫자 입력을 기준으로 보면 중복이 남았습니다. 전체 숫자 입력은 세 종류의 분자 지문과 네 개의 연속형 특성으로 구성됩니다.

| 비교 기준 | 첫 행을 제외한 중복 행 수 | 서로 다른 라벨을 포함한 그룹 수 |
| --- | ---: | ---: |
| canonical SMILES | 1 | 0 |
| 전체 분자 지문 | 294 | 34 |
| 지문 + 연속형 특성 4개 | 293 | 33 |

같은 숫자 입력에 다른 라벨이 붙은 33개 그룹은 해당 입력만 사용하는 결정적 분류기가 모두 맞힐 수 없는 사례입니다. 다만 이것만으로 원본 라벨이 잘못되었다고 단정할 수는 없습니다. 지문이 구조 차이를 충분히 표현하지 못했거나 입력에 포함되지 않은 조건이 다를 수 있습니다.

라벨을 합치거나 행을 삭제하지 않고 검토 대상으로 남겼습니다. canonical SMILES 정규화에는 염 제거, tautomer 통일, 전하 중성화가 포함되지 않았습니다.

## 2. 무작위 분할에서도 구조 중복이 남는다

라벨을 층화한 80:20 무작위 분할에서 검증 데이터 중 골격이 비어 있지 않은 물질의 **62.7%**는 학습 데이터의 물질과 골격이 같았습니다. 골격은 입체정보 없이 계산한 Bemis–Murcko 골격이며 고리 없는 분자의 빈 골격은 이 비율에서 제외했습니다. 난수 시드는 42입니다.

이 수치 자체가 성능 과대평가를 입증하지는 않습니다. 다만 새로운 구조에 대한 일반화가 목표라면 무작위 분할만으로 평가 범위를 설명하기 어렵습니다. 동일 분자와 동일 숫자 입력의 중복을 막고 별도의 골격 그룹 분할 결과도 비교할 필요가 있습니다.

## 3. 지문 열 수와 정보량은 다르다

상수 지문 열은 49개, 현재 표본에서 값이 완전히 같은 중복 열은 대표 열을 제외하고 106개였습니다. 중복 열 중 비상수 열은 58개입니다. 상수 열과 중복 열은 겹칠 수 있으므로 두 수를 단순히 더하지 않습니다.

이 결과는 현재 표본에 한정됩니다. 모델링 시 상수·희소·중복 열의 제거 기준은 학습 분할에서만 정해야 합니다. 전체 데이터에서 라벨과의 차이가 큰 비트를 골라 모델에 그대로 넣으면 검증 라벨이 변수 선택에 개입합니다.

## 4. 시각화는 모델 성능을 대신하지 않는다

상수 열을 제거한 지문을 평균 중심화한 뒤 비트별 표준화 없이 PCA를 수행했습니다. 첫 두 축은 분산의 **14.4%**를 설명했습니다. 2차원에서 클래스가 겹친다는 사실만으로 원래 고차원 공간에서 분류가 불가능하다고 판단할 수 없습니다.

연속형 특성의 분포·효과 크기·상관관계도 탐색 결과입니다. 모델의 예측력, 독성 기전 또는 인과관계로 해석하지 않았습니다.

## 후속 모델링 방향

1. 동일 분자와 동일 입력이 학습·검증에 동시에 들어가지 않도록 연결된 중복 그룹을 구성합니다.
2. 무작위 층화 분할과 골격 그룹 분할을 비교하고 각 분할의 클래스 비율과 그룹 크기를 확인합니다.
3. 변수 제거와 스케일링은 학습 분할에서만 학습합니다. 이상치와 라벨 충돌은 원인 확인 없이 자동 삭제하지 않습니다.
4. `label=1` 기준 F1과 독성 탐지 목적의 `label=0` 재현율을 구분하고 F1의 평균 방식과 AUC 계산에 사용한 양성 클래스도 명시합니다.
5. 전체 데이터를 본 뒤 만든 내부 분할은 탐색적 비교에 사용합니다. 최종 일반화 성능은 미열람 독립 데이터로 평가해야 합니다.

현재 작업의 범위는 EDA와 검증 설계입니다. 모델 학습·튜닝·예측 성능 측정은 포함하지 않았습니다.
